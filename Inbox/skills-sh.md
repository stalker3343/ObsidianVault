# skills.sh

https://www.skills.sh/

Платформа для публикации и поиска Claude-скилов (slash-команды для Claude Code).

**Что есть:**
- Рейтинг скилов по количеству скачиваний
- Поиск по категориям
- Публикация собственных скилов

**Чем полезно:**
- Найти готовые скилы для своего агента — не изобретать велосипед
- Опубликовать свои скилы (morning, capture и др.) и посмотреть насколько они востребованы у других
- Следить за тем что делают другие разработчики агентов — источник идей для улучшения бота
