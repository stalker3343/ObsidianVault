# OpenAI Codex — вайбкодинг с iPhone

OpenAI добавила бесплатную фичу в мобильный ChatGPT: Codex пишет и запускает код на ноуте, пока ты с телефона.

- Можно смотреть логи, терминал, ошибки и закидывать новые задачи
- Не даёт ноуту уйти в спящий режим, пока не закончит работу
- Вайбкодить с пляжа на iPhone — теперь реально
