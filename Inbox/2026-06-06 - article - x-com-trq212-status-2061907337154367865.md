# Dynamic Workflows — Поляков про AI агентов

## Содержание

Воркфлоу — это паттерны, которые мы давно используем, просто не называли так. Anthropic формализовал их в Claude Code.

**6 паттернов динамических воркфлоу (по Тарику):**
- **Classify-And-Act** — классификация оркестратором-скриптом
- **Fanout-And-Synthesize** — разбить на независимые куски, параллельно обработать, собрать отчёт
- **Adversarial Verification** — один агент делает, другой проверяет по чек-листу
- **Generate-And-Filter** — много вариантов → фильтр по критерию без повторов
- **Tournament** — попарные сравнения надёжнее оценок по шкале
- **Loop Until Done** — повторять пока не выполнено условие

**Ключевой инсайт:** воркфлоу — это задача, алгоритм которой ты объяснял агенту больше одного раза.

Сейчас dynamic workflows поддерживаются только в Claude Code — через ultracode или явный запрос написать workflow, запускается как слеш-команда.
