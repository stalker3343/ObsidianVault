# Claude Code скилл для SSH-подключения к серверу

Самый скачиваемый скилл в репо Полякова — не Вордстат, а маленький навык для SSH.

## Что делает

Даёт агенту (Claude Code / Codex) подключаться к удалённому серверу и выполнять команды прямо на нём: смотреть логи, перезапускать контейнеры, проверять статус.

- Указываешь адрес машины и доступ (SSH-ключ или пароль)
- SSH-ключи не читает — только выполняет команды
- В инструкции агенту лучше явно запретить чтение директории с SSH-ключами

## Приватный репозиторий без токенов

Не нужно тащить токены на сервер. Скилл форвардит SSH-авторизацию — добавляешь публичный ключ сервера в GitHub, и агент читает закрытые репозитории напрямую.

## Установка

Разворачивать в корне проекта в `.claude/skills` или `.agents/skills`.
