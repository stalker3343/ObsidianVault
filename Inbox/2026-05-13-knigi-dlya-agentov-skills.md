# Книги для агентов — серая зона и новый рынок

**Источник:** [t.me/countwithsasha/638](https://t.me/countwithsasha/638)

## Суть

Агентам нужны не PDF-книги на 500 страниц, а **навыки (skills)** — знания, которые можно вызвать во время работы. Автор переработал идею репозитория `book-to-skill` в более аккуратный компилятор: [artwist-polyakov/knowledge-compiler](https://github.com/artwist-polyakov/knowledge-compiler).

## Что делает knowledge-compiler

Собирает рабочую карту знаний для агента: понятия, решающие правила, сценарии применения, анти-паттерны, словарь, карта источников.

- Запуск через `uv run --script` без возни с окружением
- EPUB-оглавление из `toc.ncx` или `nav.xhtml`
- `source-map.json` — откуда взялась каждая идея
- Проверка дословных совпадений через n-граммы (защита от копипасты)

## Серая зона (авторское право)

- **Личный навык** из легально купленной книги — выглядит нормально (не публикуется, не продаётся)
- **Публичный навык** по чужой коммерческой книге — производное произведение, риск
- Авторы «Пиши, сокращай» отсудили 9 млн за пересказ
- OpenAI и Anthropic: пользователь отвечает за права на входные данные

## Идея для рынка

Издательства могут продавать комплект: книга + официальный skill для агента + лицензия для личного/корпоративного контура.

## Режим работы (из изображения к посту)

Фреймворк определения типа задачи перед выбором инструмента:

1. **Определи тип задачи:**
   - *Простая* — виден локальный конфликт, проверь 40 приёмов
   - *Типовая* — есть вредное взаимодействие, измерение, обнаружение, перестройка системы — проверь стандарты
   - *Сложная* — неясен корневой конфликт, сильна инерция — иди через АРИЗ-lite
2. Сформулируй конфликт без жаргона
3. Найди, что нельзя ухудшить
4. Сформулируй ИКР: что должно происходить «само»
5. Проверь ресурсы системы, подсистемы, надсистемы и среды
6. Только потом выбирай инструмент (decision-rules / playbooks / concepts / anti-patterns)
