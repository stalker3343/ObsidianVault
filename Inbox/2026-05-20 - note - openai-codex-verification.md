# Верификация аккаунта OpenAI Codex

OpenAI ужесточает проверку при входе в Codex — теперь требует верификацию через SMS или WhatsApp. В ряде юрисдикций только WhatsApp, что неудобно без нужной симки.

## Варианты решения

1. **Сервис верификации** (148р) — https://plati.market/itm/codex-sms-verified-accounts-chatgpt-openai-personal-guarantee/5867527
2. **SMS работают:** Индонезия, США, Кения, Канада, ОАЭ (из дешёвых)
3. **Device auth (без телефона):** запустить `codex login --device-auth` → выдаст 6-значный код прямо в терминале. Предварительно в настройках ChatGPT включить разрешение авторизации Codex по 6-значному коду. ✅ Работает без зарубежного номера.

## Нюансы
- США: виртуальные номера часто отклоняются (hero-sms и аналоги могут не пройти; physic — работает)
- Казахстанская симка через WhatsApp работает, но непонятно сколько аккаунтов пустит на один номер
