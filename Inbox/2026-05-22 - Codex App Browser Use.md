**Источник:** @deksden_notes

**1. Browser Use через CPA-прокси починили**
Раньше при работе через CPA-прокси не проходила авторизация в Browser Use — приходилось держать отдельный конфиг и аккаунт для прямого подключения. В Codex App build 3003 + CPA 7.1+ починили. Теперь работает без костылей.

**2. Аннотации расширили**
Аннотации — выделяем элемент UI, пишем что не так, отправляем агенту. Не нужно словами описывать кнопку. В свежем билде можно тюнинговать выделенный элемент через иконку параметров.
