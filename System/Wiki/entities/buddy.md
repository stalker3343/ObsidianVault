# Бадди (accountability partner)

Еженедельные созвоны — трёхмесячный спринт достижения целей [[artyom|Артёма]].
Возрастные, но чувствуют себя прекрасно — вдохновляют по теме здоровья.

2026-05-18 — 2026-05-24: Артём созванивался с бадди; это часть поддерживающего внешнего контура недели. В рефлексии 7-й недели Q2 созвон отмечен как факт поддержания системы, без новых отдельных советов.
