# AI для личной продуктивности

→ Связано с: [[topics/productivity]], [[topics/projects]], [[decisions/productivity]], [[SCHEMA]]

## Текущее понимание

AI/бот/wiki стали рабочей системой, а не просто идеей. Singularity даёт "что", бот добавляет "когда, зачем, после чего и в каком контексте", wiki сохраняет устойчивые выводы и связи.

Главная ценность проекта — снижать трение capture, планирования, декомпозиции мутных задач и синтеза. Главный риск — система улучшения системы начинает вытеснять сон, еду, работу, отношения и саму жизнь.

## Что работает

- План дня с ботом: помогает превратить хаос задач в маршрут.
- Декомпозиция мутных задач на первые 3 действия.
- Capture задач и мыслей через Telegram/голос.
- Wiki как слой синтеза, а не raw-архив.
- Second opinion для важных AI-планов.

## Границы проекта

Прогрессом считается новый внедрённый способ, который реально ускоряет планирование, capture, выполнение или синтез. Обычное использование Codex/бота фоном не считается новым прогрессом проекта.

Этот проект не должен поглощать все остальные. Для сессий нужно заранее задавать результат и лимит времени.

## Идеи

- Обработка постов/сообщений Telegram.
- AI-агент для Daily → недельный синтез → подкаст.
- Cron-задачи/напоминания через cc-connect.
- Изучить Hermes как open source Telegram-агента со skills и памятью.
- Для рабочей базы знаний попробовать загрузку чатов/контекста проекта в wiki по методу LLM Wiki.
