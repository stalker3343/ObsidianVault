# Поведенческие паттерны

Стабильные паттерны, подтверждённые 3+ раз. Обновляется только при новых подтверждениях или опровержениях.

→ Связано с: [[entities/artyom]], [[topics/productivity]]

## Энергия и сон

**Недосып → всё рассыпается**
Подтверждения: 2026-05-08 (3+ раз).
Механизм: недосып → нет энергии на самоконтроль → чеклисты/планы не работают → тревожность → ощущение провального дня.

**Один сдвиг в конце дня → ломает следующее утро**
Подтверждения: 2026-05-06, 2026-05-08.
Цепочка: поздно лёг → нет плана → утром не знаешь что делать → тревожность.

## Прокрастинация

**После задачи → YouTube/шортсы**
Стабильно, 3+ раз в день. Переключение на пассивный контент как разрядка.

**Прокрастинация через «полезное»**
Бот вместо работы, планирование вместо действия, разработка вместо рефлексии.
Примеры: 2026-05-08 (рефлексия → общение с ботом), 2026-05-08 (полдня на план автоматизации).

## Фокус и медитация

**Не медитировал → рассеянность весь день**
Стабильный паттерн.

**Суета утром → рассеянность**
Звонки, записи к врачам с утра — ломают фокус на весь день.
