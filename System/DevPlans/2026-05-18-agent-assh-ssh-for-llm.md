# Dev Plan: agent-assh — SSH-доступ для LLM-агентов

## Задача

Подключить `agent-assh` для удобной SSH-работы агента с VPS (например, при диагностике, деплое, настройке).

## Что это

`assh` — open-source CLI, SSH workflow helper специально для LLM-агентов.

- Установка: `npm i -g agent-assh`
- GitHub: https://github.com/izzzzzi/agent-assh
- Persistent tmux-сессия: сохраняет директорию и окружение между командами
- Компактный JSON API: большие логи не улетают целиком в контекст — агент читает только нужные строки
- Безопасный first login: пароль не передаётся аргументом команды
- Работает с: Codex, Claude Code, OpenCode и другими terminal-агентами

## Зачем для этого бота

- Диагностика VPS (место на диске, логи, процессы) — без ручного входа
- Деплой новых версий агента прямо из чата
- Разбор проблем в рантайме (например, закончилось место — 15 минут потрачено вручную)

## Шаги

1. Установить на Mac: `npm i -g agent-assh`
2. Проверить `assh connect-info` — вставить данные VPS
3. Настроить SSH-ключ через `assh key-deploy`
4. Протестировать: `assh exec "df -h"`
5. Добавить в разрешённые команды агента в `.claude/settings.json`

## Риски

| Риск | Митигация |
|---|---|
| SSH-ключ к VPS попадёт в контекст агента | Использовать `key-deploy`, не передавать пароль напрямую |
| Агент выполнит деструктивную команду | Ограничить whitelist команд в настройках |
