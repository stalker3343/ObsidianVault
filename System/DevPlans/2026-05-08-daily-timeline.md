# Dev Plan: Вывод лога дня по часам

**Дата:** 2026-05-08
**Статус:** draft

## Задача

Когда пользователь просит показать что делал сегодня / вчера по часам — бот читает дейли заметку, парсит capture-записи с временными метками и возвращает красивый таймлайн.

## Контекст

Дейли заметки хранятся в `Daily/YYYY-MM-DD.md`. Раздел `## Capture` содержит записи вида:
```
- **HH:MM** Текст записи
```
Сейчас бот делает это вручную через Read + форматирование в голове. Нужен скрипт `skills/daily_timeline.py`.

## Промпт для пользователя (триггеры в AGENT.md)

Триггеры (добавить в таблицу маршрутизации):
- `таймлайн`, `лог дня`, `что делал сегодня`, `по часам`, `выведи день`
- Опционально с датой: `что делал вчера`, `таймлайн за 7 мая`

Действие: `.venv/bin/python skills/daily_timeline.py [--date YYYY-MM-DD]`

По умолчанию — сегодняшняя дата.

## Шаги реализации

1. **`skills/daily_timeline.py`**
   - Принимает `--date YYYY-MM-DD` (default: today)
   - Читает `Daily/{date}.md`
   - Парсит строки вида `- **HH:MM** текст` из раздела `## Capture`
   - Сортирует по времени (они могут быть в обратном порядке)
   - Выводит JSON: `{ "ok": true, "date": "...", "entries": [{"time": "HH:MM", "text": "..."}] }`

2. **Форматирование на стороне бота (в AGENT.md)**
   - Бот получает JSON и форматирует в читаемый таймлайн
   - Группировка по часам опциональна — можно просто хронологический список
   - Формат вывода: `**HH:MM** — текст`

3. **Обновить AGENT.md**
   - Добавить строку маршрутизации для триггеров таймлайна

## Затронутые файлы

- `skills/daily_timeline.py` — новый скрипт
- `AGENT.md` — добавить строку в таблицу маршрутизации

## Риски

- Записи могут быть вне раздела `## Capture` — парсить весь файл или только секцию
- Дата "вчера" нужно вычислять относительно текущей даты, не захардкоживать
- Длинные записи (dev plans, мысли) — обрезать до 1–2 строк или выводить полностью (параметр `--short`)
