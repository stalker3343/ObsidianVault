# Парсер скидок Магнит / Пятёрочка / Перекрёсток

## Задача

Парсить акции и скидки в Магните, Пятёрочке и Перекрёстке. Присылать уведомление только по товарам из персонального списка интересов.

## Контекст

Скидки в сетевых магазинах обновляются еженедельно. Сейчас узнаю о них случайно — хочется получать точечные уведомления только по нужным товарам, без просмотра всего каталога.

## Шаги реализации

1. **Источники данных**
   - Магнит: `magnit.ru/promo/` или мобильное API
   - Пятёрочка: `5ka.ru/api/` (есть открытое API с акциями)
   - Перекрёсток: `perekrestok.ru/catalog/` или API приложения

2. **Список интересов**
   - Файл `wishlist.json` или заметка в Obsidian с категориями/названиями товаров
   - Примеры: мясо, рыба, молочка, кофе, орехи — задать ключевые слова

3. **Логика матчинга**
   - Сравнивать название товара со скидкой с ключевыми словами из списка
   - Порог скидки: уведомлять только если скидка ≥ 20%

4. **Уведомления**
   - Отправка в Telegram через бота (уже есть инфраструктура)
   - Формат: товар, магазин, цена до/после, срок акции

5. **Расписание**
   - Запуск раз в день (утром) или при обновлении акций
   - Cron через cc-connect или systemd timer на сервере

6. **Стек**
   - Python + requests/httpx для парсинга
   - Telegram Bot API для уведомлений
   - Хранение wishlist: JSON или Obsidian-заметка

## Риски

- API магазинов могут быть закрытыми или менять структуру — потребуется поддержка
- Пятёрочка имеет открытое API, Магнит и Перекрёсток — нужно исследовать
- Антибот-защита на сайтах — возможно нужен playwright/selenium для части источников
