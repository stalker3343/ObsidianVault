# Dev Plan: Wiki Карпати — живая база знаний обо мне

## Идея

AGENT.md — статичный снимок. Обновляется руками, быстро устаревает.

Wiki Карпати — живая база, которая растёт из:
- Ежедневных логов (Daily notes)
- Пересланных материалов (Inbox)
- Ручных добавлений
- Наблюдений бота по ходу разговоров

Я (бот) читаю нужные страницы вики в начале разговора и использую как контекст. Чем богаче вики — тем точнее и персональнее ответы.

---

## Структура: `System/Wiki/`

```
System/Wiki/
  index.md          # оглавление + краткий профиль
  health.md         # здоровье: симптомы, врачи, наблюдения в динамике
  habits.md         # паттерны поведения, что работает, что нет
  projects.md       # актуальный статус проектов (живее чем в AGENT.md)
  people.md         # близкие: кто, отношения, контекст
  work.md           # работа: стек, компания, цели, поиск работы
  learning.md       # английский, курсы, что изучает
  insights.md       # накопленные инсайты из дейли — distilled знания
  preferences.md    # предпочтения, антипатии, стиль жизни
```

Каждый файл — живой документ с датами обновлений. Не хронология, а **distilled state**.

---

## Чем отличается от AGENT.md

| | AGENT.md | Wiki |
|---|---|---|
| Обновляется | Руками, редко | Автоматически + руками |
| Структура | Плоский список | Тематические страницы |
| Глубина | Краткое описание | Детали, динамика, история |
| Источник | Я пишу сам | Дейли логи + наблюдения бота |

AGENT.md остаётся — там routing и правила. Wiki — знания о человеке.

---

## Как я использую вики

В AGENT.md добавить инструкцию:

```
При каждом разговоре читай System/Wiki/index.md.
При вопросах о здоровье — System/Wiki/health.md.
При вопросах о работе — System/Wiki/work.md.
И т.д.
```

Я сам решаю какие страницы релевантны теме разговора и читаю их через `Read`.

## Как вики пополняется

### Вариант A — вручную по запросу
"Обнови вики: я начал ходить в бассейн по средам"
→ я нахожу нужную страницу и дописываю.

### Вариант B — автоматическая дистилляция из дейли (сложнее)
Новый skill `distill_wiki.py` или крон-задача раз в неделю:
- Читает Daily/*.md за последние 7 дней
- Извлекает паттерны, инсайты, обновления статусов
- Предлагает мне (боту) обновить нужные страницы вики

### Вариант C — я сам замечаю и записываю
По ходу разговора вижу новую информацию → коротко обновляю нужную страницу.
Например: "кстати, я теперь хожу в зал по вторникам и четвергам" → пишу в `habits.md`.

**Рекомендация:** начать с A + C (руками), потом при наличии паттерна делать B.

## Шаг 1 — создать вики из AGENT.md

Первое наполнение — перенести и структурировать то, что уже есть в AGENT.md:
- Контекст пользователя → `index.md` + `people.md`
- Здоровье → `health.md`
- Активные проекты → `projects.md`
- Паттерны поведения → `habits.md`
- Работа / английский → `work.md` + `learning.md`
