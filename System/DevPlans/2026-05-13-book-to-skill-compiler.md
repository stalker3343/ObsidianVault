# Dev Plan: skill compile_book — компиляция книги в карту знаний

## Задача

Добавить в бота навык `compile_book.py`, который принимает EPUB/PDF-файл (например, «Джедайские техники» Дорофеева), компилирует его через Claude API в структурированную карту знаний и сохраняет в Obsidian vault как готовый к использованию skill-документ.

Вдохновение: [artwist-polyakov/knowledge-compiler](https://github.com/artwist-polyakov/knowledge-compiler) (пост t.me/countwithsasha/638).

## Контекст

- Бот уже умеет принимать файлы через `capture_file.py` → кладёт их в `Inbox/`
- Новый скилл — второй шаг: взять файл из vault и скомпилировать
- Только личный контур, артефакт не публикуется — серой зоны авторского права нет
- Claude API уже доступен в окружении (используется агентом)

## Шаги

### 1. Новый скилл `skills/compile_book.py`

Аргументы:
- `--file-path` — путь к файлу внутри vault (относительный)
- `--comment` — необязательный контекст от пользователя

Логика:
1. Определить тип файла (EPUB / PDF)
2. Извлечь текст посегментно:
   - EPUB: `ebooklib` → разбить по главам через `toc.ncx` / `nav.xhtml`
   - PDF: `pdfplumber` → разбить по страницам / разделам
3. Если книга большая (>100k токенов) — сделать компактную разведку структуры первым запросом к Claude
4. Вызвать Claude API (claude-sonnet-4-6) для компиляции карты знаний:
   - Понятия и концепции
   - Решающие правила (если X → делай Y, потому что Z)
   - Сценарии применения
   - Анти-паттерны
   - Словарь
   - source-map: из какого сегмента взялась идея
5. Проверить n-грамм совпадения с исходником (защита от дословного копирования)
6. Сохранить результат в `System/BookSkills/YYYY-MM-DD-<slug>.md`
7. Вернуть JSON: `ok`, `path`, `commit`, `title`, `segments_count`

### 2. Зависимости (добавить в requirements.txt)

```
ebooklib>=0.18
pdfplumber>=0.11
anthropic>=0.40
```

### 3. Маршрутизация в AGENT.md

Добавить строку в таблицу маршрутизации:

| `скомпилируй книгу: <path>`, `книга в скилл: <path>`, `разбери книгу: <path>` | `.venv/bin/python skills/compile_book.py --file-path ... --comment ...` |

Типичный флоу:
1. Пользователь отправляет EPUB → `capture_file.py` кладёт в `Inbox/`
2. Пользователь пишет «скомпилируй книгу: Inbox/джедайские-техники.epub»
3. Агент вызывает `compile_book.py --file-path Inbox/джедайские-техники.epub`
4. Результат → `System/BookSkills/2026-05-13-dzhedajskie-tehniki.md`

## Риски

| Риск | Митигация |
|------|-----------|
| Книга > контекстное окно Claude | Сегментация + разведочный запрос структуры |
| Плохое качество PDF (сканы) | Сообщить пользователю, предложить EPUB |
| Стоимость API на большой книге | Логировать токены, предупреждать перед запуском |
| Авторское право | Только личный vault, не публиковать, n-грамм проверка |
| EPUB без toc.ncx | Fallback: разбивка по размеру + Claude определяет структуру |
