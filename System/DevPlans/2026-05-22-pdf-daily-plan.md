# Dev Plan: генерация плана дня в PDF

**Дата:** 2026-05-22
**Статус:** идея

---

## Задача

Бот формирует план дня утром в чат — но его неудобно листать и возвращаться к нему. Нужно генерировать план в виде PDF-файла и отправлять в Telegram одним документом.

## Контекст

**Инсайт (2026-05-22):** план от бота помогает стартануть и не думать лишнего — даже если он неточен. Раньше это делалось вручную в тетрадке («что после чего») + Singularity («конкретно что»). Бот объединяет оба источника. PDF сделает план удобнее для беглого взгляда в течение дня.

---

## Функциональность MVP

По команде `/plan_pdf` или автоматически после утреннего брифа:

1. Взять данные из `System/Today/schedule.md` (календарь) и `System/Today/singularity-tasks/YYYY-MM-DD.md` (задачи)
2. Сформировать структурированный план с временными блоками
3. Сгенерировать PDF
4. Отправить файл в Telegram через `cc-connect send --file`

### Формат PDF

```
[Дата и день недели]
[Фокус недели — 2-3 строки]

РАСПИСАНИЕ
10:30  Дейли
16:15  Фестиваль вина

ЗАДАЧИ НА СЕГОДНЯ          ПРОСРОЧЕННЫЕ
✦ Тест по Vue               ! Урок РСВ (+1д)
✦ Тренировать танец         ! Зубная нить (+2д)
○ Посмотреть отпуска        ...
```

## Шаги реализации

1. **`skills/generate_plan_pdf.py`**
   - Читает `schedule.md` и `singularity-tasks/YYYY-MM-DD.md`
   - Читает фокус недели из `System/WeeklyFocus/`
   - Формирует структуру плана
   - Генерирует PDF через `reportlab` или `weasyprint` (из HTML-шаблона)

2. **HTML-шаблон** `skills/templates/daily_plan.html`
   - Чистый минималистичный дизайн
   - Две колонки: расписание + задачи
   - Просроченные выделены цветом

3. **Отправка через cc-connect**
   - `cc-connect send --file /tmp/plan-YYYY-MM-DD.pdf`

4. **Триггер**
   - Команда `/plan_pdf` в Telegram
   - Опционально: автоматически после `dump_agenda_to_vault` на старте сессии

## Риски

| Риск | Митигация |
|---|---|
| `weasyprint` тяжёлый (~150MB зависимостей) | Попробовать `reportlab` — легче, но сложнее верстать |
| PDF неудобно читать на телефоне | Сделать альтернативу: красиво сформатированное сообщение в Telegram (MarkdownV2) |
| Шрифты на VPS без GUI | Включить базовые шрифты в Docker-образ |
