# Weekly Reflection Agent

## Задача
Субагент, который анализирует заметки за последние 7 дней и выдаёт краткий структурированный ответ. Работает изолированно — не засоряет контекст основного чата, возвращает только результат. Работает внутри Claude Code Pro подписки, без прямых вызовов API.

## Вопросы / темы для анализа

**Я анализирую сложности**

**Планы и Задачи**
- не выполнил
- недоработал
- избегал
- игнорировал
- прокрастинировал

**Воровало**
- внимание
- время
- концентрацию
- мыслетопливо

**Дискомфорт**
- напрягало
- раздражало
- самосаботаж

## Контекст
Пользователь хочет не пересказ дневника, а выжимку по проблемным паттернам недели — быстро и по делу.

## Подход: `.claude/agents/` (Способ 2)

Кастомный агент описывается как markdown-файл в `/srv/telegram-obsidian-agent/.claude/agents/weekly-reflection.md`. Claude Code автоматически "знает" о его существовании и основной агент может вызвать его по имени через `Agent` tool.

**Преимущества перед скриптом с API:**
- Не требует отдельной оплаты API — работает внутри Pro подписки
- Системный промпт агента описан один раз в файле
- Агент сам использует Read/Glob инструменты — не нужен Python-скрипт для чтения файлов

## Шаги реализации

1. Создать `/srv/telegram-obsidian-agent/.claude/agents/weekly-reflection.md`
   ```markdown
   ---
   name: weekly-reflection
   description: Анализирует daily-заметки за 7 дней по проблемным паттернам
   tools: Read, Glob
   ---
   Ты аналитик дневника. Читаешь /srv/ObsidianVault/Daily/ за последние 7 дней.
   Отвечаешь строго по структуре (без воды, только факты из заметок):
   - Планы и задачи: не выполнил / недоработал / избегал / прокрастинировал
   - Воровало: внимание / время / концентрацию / мыслетопливо
   - Дискомфорт: напрягало / раздражало / самосаботаж
   Если в заметках нет данных по теме — пропустить.
   ```

2. Основной агент (AGENT.md) при команде `/weekly` вызывает субагента через `Agent` tool, получает текст и сохраняет в `Inbox/YYYY-MM-DD - weekly-reflection.md`

3. Добавить маршрутизацию в `AGENT.md`: `/weekly`, `недельный анализ` → вызов субагента `weekly-reflection`

## Затронутые файлы
- `.claude/agents/weekly-reflection.md` (новый)
- `AGENT.md` (добавить строку маршрутизации)

## Риски
- Заметки могут быть короткими или пропущенными — агент должен пропускать пустые дни без ошибки
- Если daily за несколько дней большие — субагент может упереться в лимит контекста Pro; решение: читать только строки с тегом `thought`
