# Weekly Reflection Agent

## Задача
Скил или субагент, который анализирует заметки за последние 7 дней и выдаёт краткий структурированный ответ. Работает изолированно — не засоряет контекст основного чата, возвращает только результат.

## Вопросы / темы для анализа

**Я анализирую сложности**

**Планы и Задачи**
- не выполнил
- недоработал
- избегал
- игнорировал
- прокрастинировал

**Воровало**
- внимание
- время
- концентрацию
- мыслетопливо

**Дискомфорт**
- напрягало
- раздражало
- самосаботаж

## Контекст
Пользователь хочет не пересказ дневника, а выжимку по проблемным паттернам недели — быстро и по делу.

## Шаги реализации

1. Скрипт `skills/weekly_reflection.py`
   - Читает все `Daily/YYYY-MM-DD.md` за последние 7 дней
   - Собирает текст в один промпт
   - Вызывает Claude API с инструкцией отвечать строго по темам выше
   - Возвращает JSON `{ ok, summary, path }` и сохраняет результат в `Inbox/YYYY-MM-DD - weekly-reflection.md`
2. Маршрутизация в AGENT.md: команда `/weekly` или `недельный анализ` → запустить скрипт
3. Агент получает только итоговый JSON, не читает сырые заметки в основном контексте

## Затронутые файлы
- `skills/weekly_reflection.py` (новый)
- `AGENT.md` (добавить строку маршрутизации)

## Риски
- Заметки могут быть короткими или пропущенными — скрипт должен gracefully обрабатывать пустые дни
- Стоимость токенов на большой контекст недели — можно ограничить только секциями `thought` из daily
