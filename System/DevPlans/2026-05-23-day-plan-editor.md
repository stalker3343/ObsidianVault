# Dev Plan: Визуальный редактор плана дня

date: 2026-05-23
status: side-feature / idea
priority: low

---

## Идея

Бот генерирует план дня текстом. После — пользователь хочет его "докрутить":
переставить задачи по времени, убрать лишнее, добавить своё.
Сейчас это делается словами ("перепланируй учитывая..."), что медленно.

Нужен лёгкий UI — редактор плана прямо из Telegram.

---

## Концепция

Бот присылает план дня как интерактивный список временных блоков.
Пользователь может:
- перетащить задачу в другой слот
- убрать задачу (скрыть на сегодня, не удалять из Singularity)
- добавить произвольную задачу в слот
- нажать "Сохранить" — план фиксируется в Daily и/или возвращается боту как контекст

---

## Варианты реализации

### Вариант А — Web App (Telegram Mini App)
- Бот генерирует план → сохраняет во временный JSON
- Отправляет кнопку "Открыть редактор" → открывается Telegram Mini App (веб-страница)
- UI: drag-and-drop список временных блоков (например, на SortableJS или @dnd-kit)
- После сохранения — Mini App отправляет обратно отредактированный JSON боту
- Бот фиксирует план в Daily

Плюсы: полноценный drag-and-drop, красиво
Минусы: нужен хостинг Mini App, разработка фронта

### Вариант Б — Inline-кнопки в Telegram (без фронта)
- Бот присылает план блоками, у каждого блока кнопки: [↑] [↓] [✕] [+]
- Пользователь жмёт кнопки — бот редактирует сообщение
- Проще в реализации, но drag-and-drop невозможен — только пошаговые перестановки

Плюсы: не нужен фронт, работает нативно в Telegram
Минусы: неудобно для сложных перестановок, много нажатий

### Вариант В — Редактируемый markdown-файл в Obsidian
- Бот сохраняет план дня в `System/Today/day-plan.md` в структурированном формате
- Пользователь редактирует файл в Obsidian вручную
- Бот умеет читать этот файл как "принятый план" (по запросу)

Плюсы: нулевая разработка, Obsidian уже есть
Минусы: нет drag-and-drop, надо открывать Obsidian отдельно

---

## Рекомендация

Начать с Варианта В как MVP (ноль разработки).
Если понравится workflow — делать Mini App (Вариант А).

---

## Затронутые компоненты
- Новый скрипт `skills/save_day_plan.py` — сохраняет план в `System/Today/day-plan.md`
- `AGENT.md` — маршрут: после генерации плана предлагать "Сохранить в Obsidian для редактирования?"
- (для Mini App) отдельный сервис на FastAPI / Vercel + фронт

---

## Риски
- Telegram Mini App требует HTTPS и публичного хостинга
- Синхронизация отредактированного плана обратно боту нетривиальна
- Drag-and-drop на мобиле требует аккуратной реализации (UX)
