# Dev Plan: скилл автозаполнения итогов проектов в Excel

## Задача
Создать скилл (или подключить агента), который читает дейли-логи за 7 дней, извлекает движение по проектам и автоматически заполняет недельную таблицу Excel.

## Контекст
Сейчас Артём вручную заполняет итоги недели в Excel — тратит час и больше. Все данные уже есть в Daily/*.md. Задача — автоматизировать извлечение и структурирование этих данных в нужный формат таблицы.

## Шаги
1. Изучить структуру текущей Excel-таблицы — какие колонки, какие проекты, какой формат статусов.
2. Определить способ подключения к Excel: экспорт в CSV / запись через openpyxl / Google Sheets API.
3. Написать парсер дейли-логов за 7 дней — извлекать упоминания проектов и статусы.
4. Написать skill `weekly_projects_summary.py` или агента, который запускается по команде.
5. Связать с ботом: команда `/weekly` или автозапуск по воскресеньям.
6. Опционально: сначала показывать черновик Артёму в чат, потом записывать в таблицу.

## Затронутые файлы
- `skills/weekly_projects_summary.py` (новый)
- `AGENT.md` — добавить маршрутизацию на команду
- Excel-файл или Google Sheets (уточнить путь/доступ)

## Открытые вопросы
- [ ] Где живёт Excel-файл — локально, в OneDrive, Google Sheets?
- [ ] Какой формат таблицы — проекты по строкам, недели по колонкам?
- [ ] Как парсить «движение по проекту» из свободного текста дейли — LLM или keywords?
- [ ] Показывать черновик в Telegram перед записью или сразу писать?
- [ ] Нужен ли откат если таблица заполнена неверно?
- [ ] Запуск по команде или автоматически каждое воскресенье?
