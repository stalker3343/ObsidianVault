## Задача 1: Вынести инициализацию из AGENT.md в скрипт

### Контекст
Сейчас AGENT.md описывает 4 шага инициализации на старте каждого разговора:
- `fetch_weekly_focus.py`
- `fetch_calendar.py --current-window`
- `singularity.dump_agenda_to_vault()`
- чтение `System/Wiki/index.md`, `schedule.md`, файла дампа задач

Агент делает это руками. Хочется отдать скрипту.

### Решение
Создать `skills/morning_init.py`:
- запускает последовательно: calendar → weekly_focus → singularity dump
- возвращает JSON с полями `calendar_path`, `focus_path`, `agenda_path`
- агент читает эти три файла + `System/Wiki/index.md`

AGENT.md упрощается до одной строки:
```
На старте: run morning_init.py → прочитай пути из JSON + System/Wiki/index.md
```

### Альтернатива (без агента вообще)
Shell-скрипт `skills/morning_init.sh` запускается по cron за 5 минут до обычного времени начала дня — данные уже готовы, агент только читает файлы. Минус: не знает, когда именно начнётся разговор.

### Затронутые файлы
- `skills/morning_init.py` — новый файл
- `AGENT.md` — раздел "Контекст пользователя / Календарь / Задачи Singularity на старте" — упростить до вызова скрипта

### Риски
- Singularity MCP нельзя вызвать из обычного Python-скрипта — dump_agenda нужно оставить на агенте или вызывать через cc-connect relay
- Если один из подскриптов упал — morning_init должен возвращать частичный результат, не падать целиком

## Задача 2: Добавить "Что делаю по-другому" в WeeklyFocus

### Контекст
В файле `System/WeeklyFocus/YYYY-MM-DD.md` нет секции с ретроспективой. Пользователь хочет видеть там итоги прошлой (и позапрошлой) недели: что решил делать иначе.

### Решение
Добавить секцию `## Что делаю по-другому` в WeeklyFocus-файл текущей недели.
Источник данных — ежедневные заметки за прошлую неделю, секции типа "по-другому" / инсайты.

Вариант А — делать вручную при создании нового WeeklyFocus.
Вариант Б — скрипт `skills/weekly_retro.py`:
- берёт Daily-заметки за прошлые 7–14 дней
- ищет паттерны "по-другому", "инсайт", "решил"
- формирует bullet-список и дописывает в текущий WeeklyFocus

### Затронутые файлы
- `System/WeeklyFocus/2026-05-18.md` — добавить секцию вручную прямо сейчас (данные с прошлой недели)
- `skills/weekly_retro.py` — новый скрипт (опционально, для автоматизации)
- `AGENT.md` — добавить маршрут: при создании нового WeeklyFocus — запускать ретро

## Задача 3: Убрать список задач из саммари дня

### Контекст
При старте разговора агент выводит пользователю дамп из 44 задач — это шум. Задачи уже в Singularity, незачем дублировать в чат.

### Решение
В стартовом сообщении агента показывать только:
- события календаря на сегодня (из schedule.md)
- фокус недели (2–3 пункта, не весь список)
- ближайший день рождения если есть

Задачи — только по запросу (`что на сегодня`, `повестка`, `что горит`).

### Затронутые файлы
- `AGENT.md` — раздел "Задачи Singularity на старте": убрать инструкцию читать и выводить дамп задач в стартовом сообщении. dump_agenda_to_vault вызывать молча (для контекста агента), но не показывать пользователю.
